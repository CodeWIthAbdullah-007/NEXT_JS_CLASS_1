# 🚀 NEXT_JS_CLASS_1

A beginner-friendly **Next.js practice project** created while learning the fundamentals of Next.js.

## 📚 Topics Covered

* ⚡ Next.js Project Setup
* 📁 Project Structure
* 🏠 Pages & Routes
* 🔗 Linking & Navigation
* 🧩 Layouts
* 👶 `{children}` Concept
* 🖥️ Server Components
* 💻 Client Components
* 📡 Basic Data Fetching

## 🛠️ Tech Stack

* Next.js
* JavaScript
* React
* CSS
* npm

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/CodeWIthAbdullah-007/NEXT_JS_CLASS_1.git
```

Go to the project folder:

```bash
cd NEXT_JS_CLASS_1
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
